# BeautifulRust provenance

The Rust skill documents are copied from
https://github.com/morganlinton/BeautifulRust at commit
`b9718436d77ee7bcf17cdcb6aa27628feb95d97a` under the included MIT license.
Only skill documents and their references are vendored; no installer, MCP server,
hooks, or evaluation programs are installed or executed.

For the GPUI experiment, treat these as application guidance. Preserve the pinned
dependencies, GPUI framework contracts, canonical-read-only admission checks and
existing behavior. Do not mechanically convert GUI callback parameters or renderer
coordinates solely to satisfy a stylistic lint.
