# A confidential note

This page carries the `CONFIDENTIAL` flag: the red stamp across the article, and the badge beside
its title in every list that shows the note.

The flag marks; it does not hide. A published export carries a flagged note like any other — the
stamp travels with it, and so does every word underneath. Keeping something out of a publication is
a job for a vault of its own, not for a marker on one note inside a vault that gets published whole.
Which is why this page can sit on a public help site at all: it is a sample of the stamp, and there
is nothing confidential on it.
