# A deprecated note

This page carries the `DEPRECATED` flag, so it is the flag's own demo: the red stamp across the
article, and the badge beside its title wherever the note is listed — in backlinks, in search
results, in a tag's notes.

None of that is a judgment on the writing. A flag is a whole-note marker the author assigns and the
sidecar keeps; see [[Properties]] for how to set one, from the CLI (`track meta --flag DEPRECATED`)
or from the Meta dialog's checkboxes in the [[Web workspace]].

`DEPRECATED` is the one flag with behavior past the stamp: the search index subtracts a constant
from a deprecated note's rank, so it sits below the notes that are not. An old page stops crowding
out the page that replaced it, without anyone having to delete it.
