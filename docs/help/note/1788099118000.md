# A deprecated note

This is a sample page. It carries the `DEPRECATED` flag so the flag can be seen doing its work: the
red stamp across the article, and the badge beside the title wherever the note is listed — in
backlinks, in search results, in a tag's notes. Nothing here is actually out of date.

A flag is a whole-note marker the author assigns and the sidecar keeps; see [[Properties]] for how
to set one, from the CLI (`track meta --flag DEPRECATED`) or from the Meta dialog's checkboxes in
the [[Web workspace]].

`DEPRECATED` is the one flag with behavior past the stamp: the search index subtracts a constant
from a deprecated note's rank, so it sits below the notes that are not. An old page stops crowding
out the page that replaced it, without anyone having to delete it.
