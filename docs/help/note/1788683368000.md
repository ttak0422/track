# Maps

A `map` fence draws a slippy map with markers, right inside a note. It uses body lines,
not info-string arguments:

```map
lat: 29.245
long: 50.31
zoom: 11
type: satellite
marker: default, 29.245, 50.31, [[カーグ島]], 石油積出港
```

`lat` and `long` center the map and are required; `zoom` defaults to 10 (0–19) and `type`
defaults to `roadmap`. Each `marker` line carries type, latitude, longitude, a wiki link, and
a description (which may contain commas). Marker popups use the shared wiki-link component,
including display aliases; descriptions render as text, never HTML.

Tiles load on demand: `roadmap` uses OpenStreetMap, `satellite` Esri World Imagery, `hybrid`
imagery plus reference labels, and `terrain` Esri World Topo Map. Attribution stays visible.
Invalid input stays a code block; if the map or its tiles fail, an OpenStreetMap link is
offered instead.

Geocoding, query-driven markers, and custom marker icons are not implemented.
