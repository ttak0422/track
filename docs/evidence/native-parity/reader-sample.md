# 日本語の読書面と情報の階層

長い日本語の文章と Latin text 0123456789 が混在していても、本文の幅と行間が読みやすさを保ちます。
読書面は余白と罫線で区切り、図表には広い領域を使います。
文字の大きさを変えても、段落と見出しの関係を保ちます。

## 本文は読みやすい幅に

一枚の読書面でノートを読み、関係する情報へ移動できます。
基本の本文幅は40emで、幅の設定を変えたときは図表とともに広がります。

- 日本語と英数字の混在を確認します。
- キーボードでも操作できる状態を維持します。

```swift
let reading = "日本語と Latin text"
let wideFigure = "Code occupies the full figure column beyond the prose measure."
```

| 種別 | 意味 | 表示 |
| --- | --- | --- |
| 本文 | ノートを読む | 十分な行間と文字の濃さ |
| 図表 | 構造を理解する | 本文より広い幅 |
